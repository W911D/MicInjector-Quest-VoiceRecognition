# Contributing

Thanks for helping test this experimental Quest audio-injection project.

## Before opening an issue

Please check the README and troubleshooting guide first. Avoid posting personal information, Wi-Fi credentials, ADB pairing codes, private IP information, or unredacted diagnostic dumps.

## Useful test details

When reporting a compatibility issue, include as many of these as possible:

- Headset model.
- Headset OS version.
- Windows version.
- Node.js version.
- VRChat or target app version.
- Capture preset used (`VOICE_RECOGNITION` or `CAMCORDER`).
- Whether ADB connects successfully.
- Exact error output, with personal details redacted.
- Whether the Windows client reports the expected playback device.

Do not claim support for a device or app based on a successful build alone. Reports should distinguish a successful compile, a running injector, and confirmed microphone delivery inside the target app.

## Changes

Keep pull requests focused. Explain why the change is needed, how it was tested, and which headset/app combinations were verified. Do not add private device addresses, access tokens, or local machine paths to documentation or examples.
