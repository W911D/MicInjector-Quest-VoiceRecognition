# Upstream project and licensing

This project is an experimental modification of [yume-chan/MicInjector](https://github.com/yume-chan/MicInjector), an Android virtual microphone demonstration.

## Upstream attribution

The original MicInjector project provides the Android audio-policy injector and the original Windows-side client. This repository contains changes intended to test audio injection with the `VOICE_RECOGNITION` capture preset on Meta Quest hardware.
