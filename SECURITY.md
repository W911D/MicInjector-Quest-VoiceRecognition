# Security

This is an experimental project that connects a Windows PC to an Android-based headset through ADB.

- Never commit ADB pairing codes, Wi-Fi passwords, access tokens, private keys, or personal diagnostic dumps.
- Redact personal IP addresses, usernames, and local file paths before sharing logs.
- Do not publish a security-sensitive issue with exploit details or private data. Contact the repository owner privately first.
- Treat APKs and build artifacts as executable code. Only install artifacts from a source you trust and inspect changes before running them.

This project does not currently provide a supported security-response SLA.
